# Живой тест наклона и усиление захвата у пола

Обновление: новая версия прошла живые проверки, включая низкий захват обоими
контроллерами. Результаты: `body-floor-live-validation-47732-20260921.md`.

Предыдущая DLL: `82d78f18912f0b3838de7c14381786651254fe50e6377a43549629dd14d41301`.
Живой процесс: PID30744, OpenXR Simulator. Положение головы перед тестом:
(0;1,7;0), нейтральные углы. Пользователь отдельно уточнил необходимость
опускать HMD при тесте и попросил более глубокий наклон для захвата с пола.

## Что показала предыдущая сборка

Свежие символы и имена620 костей сохранены в `build/body-bend-live-30744/`.
`live_bend_probe.py` использует VM_READ и штатный файловый pose-channel
симулятора, возвращает исходную позу в finally. Клавиши и память игры не
изменяет. Готовые model transforms проверяются двойным чтением кеша;
служебные scalar-поля — соседние наблюдения, не доказательство одного вызова.

- Простой взгляд вниз50°: угол корпуса0°, перемещение персонажа0мм.
- Дуга с опусканием и движением HMD вперёд, взгляд вниз50°: распознано49,55°,
  конус60°, маска кеша менялась476→488→476. После выпрямления угол0°.
- Поворот головы45° в наклоне: конус60°, изменение body realign0°.
- Найден дефект: на входе/выходе дуги CCT сдвигал тело до87,4мм. В конце
  возвращался к исходному месту, но удержание наклона оставляло22,2мм сдвига.

Пользовательские настройки во время теста: обычный конус20°, взгляд вниз45°.
Они не сбрасывались на значения по умолчанию.

## Исправления по результатам

1. В CCT передавалась дуга, умноженная на вес плавного появления позы. Остаток
   становился ложной просьбой идти. Теперь измеренная дуга исключается целиком;
   плавное включение применяется только к видимой позе. Добавлен тест полной
   цепочки tracker→Movement: старый код87,823мм, исправленный0мм.
2. Для низкого захвата добавлен вывод недостающего наклона по физическому
   опусканию шеи и взгляду вниз, по идее reach-cue из бэкапа. Одного pitch без
   физического опускания недостаточно. Дополнительный наклон не превращается
   в вымышленное горизонтальное движение для CCT.
3. Сгибание корпуса усилено до75°: таз получает60% сгибания, поясница85%, верх
   позвоночника100%, поверх принятой сутулости. При одинаковом входе0,7рад
   череп теперь смещается вперёд примерно406мм вместо305мм.
4. При глубоком опускании стопы захватываются до физического приседания, а
   затем колени решаются к этим контактам. Иначе стопы уходили под пол вместе
   с тазом. В подтверждённом наклоне учтён8см нейтральный offset slot90 и
   уменьшен порог приседания до2см; старый20см порог оставлял кисти выше цели.
5. Убрано зависание последних сантиметров сглаженного приседания после
   выпрямления: остаток теперь доходит до нуля.

## Проверки новой версии

- VRIK32/32, roomscale33/33.
- Низкая цель обеих кистей: model Z=0,15м, ошибка справа0,000068мм,
  слева0,000052мм. Ограничения длины рук сохранены.
- Передняя нормаль груди направлена к полу (вертикальная составляющая−0,99863).
- Стопы и их ориентации сохраняются при глубоком опускании; выход из наклона
  возвращает таз, нативную анимацию ног и теней.
- Живой `--case floor` теперь задаёт pitch65° и опускает HMD примерно до0,8м
  вместо1,33м у первоначальной дуги50°. Исходная высота восстанавливается.

Логи: `build/body-floor-vrik-tests.log`, `build/body-floor-roomscale-tests.log`.
Новая DLL требует повторного живого прогона после установки и перезапуска.
