# Плавное подтягивание, камера и осанка

Пользователь: после границы5см тело выглядит телепортирующимся; камера нужна
в20см перед шеей и на10см выше прежней опоры; грудь всё ещё выступает вперёд.

## Измерение до изменения

PID3536, свежие символы получены через x64dbg. Проба симулятора:
4см → 5,2см → 8см → исходное положение. Положение HMD восстановлено в finally.
Чтение диагностики — VM_READ, без правок памяти игры и без клавиш.

- 4см: CCT-смещений не было.
- Пересечение5см: за один шаг запрошено **27,419мм**, dt19,400мс.
- Возврат: максимальная подача **24,131мм**, dt16,189мс.
- Ошибок чтения:0.

Причина: перемещение использовало тот же быстрый экспоненциальный коэффициент
с постоянной25мс, что и поворот тела. Сразу после включения выбиралась большая
часть всего зазора. Наличие нескольких промежуточных шагов само по себе не
делало начало движения плавным.

## Изменения

- Для перемещения добавлен отдельный критически затухающий контроллер со
  скоростью в состоянии. Он начинает из покоя, разгоняется и тормозит у цели.
  Около95% зазора выбирается за0,24с; завершающий остаток не больше0,5мм.
  Сохраняются свободная зона, возврат к её центру, native CCT, потребление
  отвергнутого стеной запроса и непосредственное движение камеры.
  Поворот тела продолжает использовать прежний отдельный алгоритм.
- Камера: нейтральная верхняя шея +20см вперёд; reference-глаза +10см вверх.
  Нейтральная поза для камеры и живая поза используют общий профиль осанки.
- Верхняя спина округляется сильнее к верхним позвонкам, до12°. Добавлено
  отдельное смещение грудного сустава назад на2см. Шея распределяет обратный
  изгиб; ориентация головы сохраняет привязку к HMD.
  Таз и локальная игровая анимация ног сохраняют предыдущую схему.

На сохранённом rig контрольная точка передней поверхности груди ушла назад
на11,380мм. Грудной сустав расположен позади верхней шеи на69,552мм вместо
49,375мм. Проверяется именно положение поверхности, а не только угол кости:
один поворот мог бы дополнительно выдвинуть грудь вперёд.
