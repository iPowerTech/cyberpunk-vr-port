## Причина этого падения

Чтение дампа выполнено `tools/crash/read_dump.py`, затем данные/инструкции
проверены непосредственно в дампе и через IDA 9.2 idalib. IDA MCP не был
подключён, поэтому использована существующая локальная headless-база игры.

Исключение: `0xC0000005`, поток27912, `Cyberpunk2077.exe+0x682219`.
Оно возникло в виртуальном вызове `call [r8+0x210]`:

```text
+682206  mov  r9, rax
+682209  call +4E96E0     ; SetupDefault
+68220E  mov  r8, [r9]
+682216  mov  rcx, r9
+682219  call [r8+210h]   ; fault
```

Оригинальная `SetupDefault` — leaf-функция, не меняющая R9. Её игровой
вызыватель использует это свойство и сохраняет там живой указатель.
Обычный C++ detour вызывал `InvalidatePoseAddress`, который вправе менять
volatile-регистры по Win64 ABI. После возврата R9 уже указывал в другую память:
`0x2086161b1a0`, R8=`0x20861869470`, виртуальный адрес вызова —
неканонический `0x3db66c6abe0906a9`. Это соответствует #GP и сообщению
REDEngine о доступе к `0xFFFFFFFFFFFFFFFF`.

Таким образом, это дефект перехвата инициализации камеры. HandCollision
содержал отдельный известный риск; данный дамп не показывает падение в нём.
Упоминания функций в stack scan сами по себе не считались кадрами стека:
скан не является unwind. Вывод основан на fault-инструкции, регистрах,
предшествующем вызове и проверке фактических clobber-наборов leaf-функций.

## Исправление DLL

`src/Hooks/CameraPoseLeafThunks.asm` сохраняет 7 volatile GPR, флаги и XMM0–5
вокруг служебных C++ вызовов. SetupDefault получает исходные регистры перед
переходом к оригиналу. SetupCopy получает исходное состояние, затем его
собственные результаты сохраняются на время публикации ID. Receipt остаётся
локальным для вызова: захват до копирования, публикация после.

Добавлены стандартные unwind-описания MASM и сохранение RBP. Размер, выравнивание
и тривиальный деструктор receipt проверяются при компиляции. Сам механизм
идентичности MAIN/VRCAM и принятые пользователем изменения VRIK сохраняются.

Проверки: 16/16 в `build/pose-identity-tests`. Новые тесты исполняют настоящие
байты двух функций игры и сравнивают обычный вызов с перехваченным, включая
копирование на тот же адрес. Callback намеренно портит volatile-регистры.
Контрольный старый C++ detour нарушает R8/R9/R10/R11 и тест ожидаемо отклоняет его.
