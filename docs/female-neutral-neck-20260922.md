# Neutral Neck для женского тела

Пользователь утвердил положение кистей на лестнице и попросил женскому телу
forward+10см, затем коммит без Co-authored-by.

В PID27168 GetResolvedGenderName() вернул Female. Это тот же признак тела,
который использует существующий TacticalBelt для выбораma/wa, не пол голоса.
VRIK_DoArmPlayer теперь читает его на игровом потоке через RTTI при каждом
связывании rig. Признак входит в fingerprint rig и передаётся в neutral-neck
расчёт обоих смещений: относительно камеры и относительно центра глаз.

Female получает+0.10м вперёд от нейтральной шеи; Male/неопределённый тип
сохраняет+0.15м. Вертикальная привязка остаётся+0.10м над нейтральными глазами.
Динамический вызов не добавляется в анимационный solve. Оба camera paths
используют существующую общую публикацию neutral mount.

8/8 проверок: neck mount, female mount с последовательными female/male
перепривязками, rig rebind, combat HMD, swimming, ladder upper, baked rung,
ladder reach. Женский forward меньше мужского на5см, высота не меняется,
камера и eye-bound VRIK используют один профиль. Release DLL собрана.

резервная копия/отчёт: build/roomscale-plugin-deploy-20260922-201603.
