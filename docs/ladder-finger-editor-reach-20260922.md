# Лестница: редактор пальцев, 100см и усиленный плечевой пояс

Продолжение после DLL68fab95499b1. Пользователь попросил больше параметров
пальцев, порог автодолезания100см и более сильную, чем пешком, протракцию
лопатки/ключицы/плеча на лестнице.

## Исходное состояние

PID14664, bind4, LocomotionDetailed10. Только read-only диагностика через
свежие символы совпадающего DLL/PDB; ввод/позы не подменялись.
Снимок build/ladder-live-14664/girdle-before.json. По исходному коду лестница
использовала обычный пеший профиль ReachGirdle: onset94%, full114%,
protract3.5см, elevate1.5см, clavicle12°, shoulder glide1.5см, scapula share60%.
В игровом vrport.ini явно сохранено xr_ladder_finish_distance=0.800;
одной замены исходного default недостаточно.

## Редактор

Ladder rung fingers сохраняет прежние пять общих curl и preview в overlay.
Добавлены вкладки Left hand / Right hand с отдельными29 углами на руку:

- Для четырёх пальцев: Base/Middle/Tip bend, Spread, Roll, Palm bend.
- Для большого: Base/Tip bend, Abduction, Roll, Opposition.
- Все58 добавочных углов по умолчанию0. Есть сброс углов текущей руки
  и копирование на другую; общий curl при этом не сбрасывается.

Редактируются rotations нужных именованных суставов. Позиции, scale,
ладонь/запястье, соседние суставы и другая рука не переписываются.
Потомки естественно следуют изменённому родителю. Измеренные оси пальцев
данного rig: flex=-Z, spread=Y, roll=X; thumb CMC получает opposition/spread/roll.
Боковой хват и верхние поручни сохраняют отдельно снятые нативные позы.

Настройки сохраняются как xr_ladder_rung_{left/right}_{finger}_{channel}.
Каналы base/middle/tip/spread/roll/cup, значения в градусах. Для thumb
несуществующий третий joint (tip channel) не показывается и не сохраняется;
его реальный второй сустав хранится в middle, в UI называется Tip bend.
Парсер ограничивает значения; нечисловое значение заменяется0.
Preview, как раньше, действует только с VRIK на лестнице при открытом overlay.

## Досягаемость и выход

SolveArm получает явный ladderReach из одного poseLadder решения для обеих
рук. Пеший и автомобильный профили сохранены. Для лестницы:

| Параметр | Пешком | Лестница |
|---|---:|---:|
| Начало помощи, доля длины руки |94%|88%|
| Полная помощь |114%|110%|
| Запрос протракции |3.5см|6см|
| Подъём плечевого пояса |1.5см|3.5см|
| Предел добавочного поворота ключицы |12°|20°|
| Добавочное скольжение плечевого сустава |1.5см|2.2см|
| Доля движения, передаваемая лопатке |60%|75%|

Ключица вращается вокруг прежнего неподвижного корня, её длина не растёт.
Помощь плавно зависит от вытягивания руки и исчезает при расслаблении.
Root/таз/ноги остаются нативными. Порог автодолезания изменён на1.0м;
сохранились подтверждённый5см подъёмный жест, отмена стиком/обратным жестом,
пауза, tracking loss, таймаут и штатный выход через MoveY.
