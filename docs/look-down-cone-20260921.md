# Расширение free-look при взгляде вниз

Пользователь подтвердил предыдущую сборку в шлеме и попросил расширять конус
до30° при взгляде вниз, чтобы можно было брать предметы с нагрудного пояса.

Добавлен F10 → VRIK → **Free-look cone when looking down**, по умолчанию30°,
диапазон0–90°. Значение сохраняется в `xr_body_free_look_down_deg`.
Слайдер обычного конуса остаётся отдельным. Эффективный конус показан рядом
с диагностикой поворота тела.

Расширение плавно начинается при наклоне10° вниз и достигает выбранного
значения при30° вниз. Взгляд вперёд/вверх сохраняет обычный конус. Дополнительная
настройка никогда не сужает обычную зону: значение ниже обычного отключает
расширение. При возвращении головы вверх обычное следование возобновляется.

Pitch вычисляется по вертикальной компоненте направления взгляда, из того же
пакета HMD, что и yaw. Результат не зависит от поворота в стороны и локального
roll. Recenter-база в этом runtime содержит только yaw, поэтому не меняет
вертикаль для такого определения наклона.

Также исправлено поведение уже активного доворота: если конус расширился и
голова оказалась внутри новой зоны, старое следование прекращается. Простое
увеличение порога без этого оставляло бы пояс движущимся до окончания доворота.
Позиционный контроллер тела, калибровка камеры и осанка не менялись.

Проверки: **31/31** в `build/roomscale-tests`. Новый сценарий покрывает
взгляд вверх/вниз, сочетания yaw/pitch/roll, знак quaternion, плавный переход,
пользовательское значение, сохранение более широкого обычного конуса,
остановку активного доворота и возобновление после подъёма головы.

Контрольный прогон с прежним `BodyFollowZone.hpp` ожидаемо отклонён:
`old body turn continues while head is inside widened cone`.
