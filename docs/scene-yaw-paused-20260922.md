## Исправление

Для обычных staged/cinematic tiers2–5 добавлен тот же общий native MAIN
heading, который уже используется в машине. Его исходная ориентация
снимается до VR write; VRCAM не выбирает отдельный yaw. Device и внешний
scene/braindance path сохраняют свои ветки. В обычном tier1 остаётся прежний
пеший источник. SceneStickYaw учитывается один раз, включая bootstrap.

В LocateCamera публикация сцены использует завершённую композицию writer
только с тем же poseId и tracking origin. Её базовый yaw восстанавливается
из составленного quaternion и его собственного HMD sample, а не читается
из более нового независимого body yaw. До готовности такой пары Locate
не перезаписывает общий headQuatComposed своим отдельным ответом.
Прямых дополнительных записей в соседний глаз/дескрипторы и расширения
допусков поиска pose label нет.
