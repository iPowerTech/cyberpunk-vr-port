# Отдельное отключение VRIK в сценах автомобиля

В overlay → VRIK добавлены независимые списки:

- `Suspend VRIK in cutscenes (on foot)`;
- `Suspend VRIK in cutscenes (vehicle)`.

Набор значений одинаков: Never, Tier2+, Tier3+, Tier4+, Tier5. В mounted-позе
`AnimPose` использует автомобильный порог; он действует и для passenger Combat.
Выбор контекста совпадает с выбором режима самого решателя. Пешие ограничения
roomscale/body rotation используют пеший порог, а в машине эти два режима
по-прежнему выключены независимо от настройки VRIK.

Существующий ключ `xr_cutscene_suspend_tier` сохраняет пешее значение.
Новый `xr_vehicle_cutscene_suspend_tier` хранит автомобильное. Чтение INI,
UI snapshot, применение UI и запись файла обновлены вместе. Если нового ключа
нет, автомобиль наследует прежний общий порог для совместимости; при сохранении
настроек оба значения записываются явно и далее изменяются независимо.
Новые поля добавлены в конец структур настроек.

Проверены разные сочетания порогов, Never только в одном контексте, переход
между автомобилем и пешим режимом, отсутствие нового ключа и явное отдельное
значение. `roomscale_scene_suspend`, `roomscale_gameplay`,
`roomscale_transitions` прошли (3/3).

Игра была закрыта, автоматически не запускалась. Настройки и калибровка при

чтении новый автомобильный порог наследует 2, а при сохранении UI получит
собственный ключ.
